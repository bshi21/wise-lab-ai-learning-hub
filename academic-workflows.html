MORNING BRIEF · HOW TO RUN IT

把“早间简报”做成可审阅流程，而不是自动发送。

本网站不会执行简报；这里说明应如何在获批准的 Microsoft 365 环境中逐步尝试。

  1. 限定范围。 先只选择当天日程、自己负责的任务或经批准的项目材料；不要默认读取私人邮箱、WhatsApp 或受限研究记录。
  2. 先用 Scheduled prompt。 在可用的 Microsoft 365 Copilot 中按工作日设置固定时间，要求生成“草稿简报”，并保存到 Copilot 页面或聊天中等待人工审阅。
  3. 由责任人复核。 检查日期、行动项、参与者、敏感内容和建议；需要发送时，由人决定收件人、编辑并发送。
  4. 跨系统才考虑 flow。 只有确实需要汇总多个获批准来源时，才在 QUT 审批后使用 Power Automate scheduled flow 与最小权限 connector；flow 应创建草稿或待审项目，而非自动发送。

AUTOMATION REQUIRES AN APPROVED PATH

“早间简报”是一个设计场景，不是一键承诺。

在尝试任何自动简报前，先确定来源系统；确认 QUT 批准的 connector 与许可证；设定最小数据范围和明确接收人；再要求用户在采取行动前复核输出。首发培训优先覆盖机构管理的 Outlook、Teams、Calendar、To Do、Planner、OneDrive 和 SharePoint，具体取决于 QUT 配置。
